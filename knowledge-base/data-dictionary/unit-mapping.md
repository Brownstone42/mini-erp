# Unit Mapping

| Field | ความหมาย |
| --- | --- |
| sourceUnitKey | คีย์ normalize จากหน่วยที่พบ ใช้เป็น Primary Key |
| sourceUnitText | ข้อความหน่วยที่พบตามที่ผู้ใช้ระบุ |
| standardUnitText | ชื่อหน่วยมาตรฐานที่ใช้รวมและเปรียบเทียบจำนวน |
| noteText | หมายเหตุเพิ่มเติม (ถ้ามี) |
| createdByUid | ผู้สร้างหรือผู้บันทึกล่าสุด |
| createdAt | เวลาสร้าง |
| updatedAt | เวลาแก้ไขล่าสุด |

ตารางนี้ไม่มี factor เพราะเป็น alias ของหน่วยเดียวกัน ไม่ใช่การแปลงหน่วย
