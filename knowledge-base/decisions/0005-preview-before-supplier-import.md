# Decision 0005: Preview ก่อนยืนยัน Supplier Import

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## การตัดสินใจ

การ Import Supplier ต้องแบ่งเป็นสองขั้น:

1. ผู้ใช้ Upload ไฟล์ ระบบอ่าน แปลง และตรวจสอบข้อมูล แล้วแสดง Preview
2. ผู้ใช้ตรวจสอบผลและกดยืนยัน จึงเริ่มสร้างหรืออัปเดต Supplier

## กฎของ Preview

- ห้ามเปลี่ยนข้อมูล Supplier ก่อนผู้ใช้กดยืนยัน
- แสดงจำนวนรายการทั้งหมด รายการสร้างใหม่ รายการอัปเดต และรายการผิดพลาด
- แสดงปัญหาให้ผู้ใช้ระบุได้ว่าเกิดกับ Supplier และ field ใด
- Preview เป็นแบบอ่านอย่างเดียวและห้ามแก้ไขข้อมูล Supplier บนหน้า Preview
- หากข้อมูลผิด ผู้ใช้ต้องแก้ที่ Express แล้ว Export และ Upload ไฟล์ใหม่
- หากผู้ใช้ยกเลิก ต้องลบข้อมูลและไฟล์ชั่วคราวของรอบนั้น
- หากพบข้อผิดพลาดแม้แต่หนึ่งรายการ ต้องบล็อกการ Import ทั้งไฟล์
- การ Import ต้องสำเร็จทั้งชุด หรือไม่มีการเปลี่ยนแปลงข้อมูลเลย
