# Decision 0009: ไฟล์ Supplier เป็น Full Snapshot

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## การตัดสินใจ

ไฟล์ Supplier ที่ Export จาก Express และ Upload เข้า ERP ต้องประกอบด้วย Supplier ครบทั้งหมดทุกครั้ง

ระบบไม่รองรับการ Upload ไฟล์ที่กรองเฉพาะบางประเภทหรือบางช่วงรหัสใน flow นี้

## ผลกระทบ

- Supplier ที่ไม่พบในไฟล์รอบล่าสุดสามารถเปลี่ยนเป็นไม่ใช้งานได้
- หน้า Preview ต้องเปรียบเทียบข้อมูลทั้งไฟล์กับ Supplier ทั้งหมดใน ERP
- การสร้าง อัปเดต เปิดใช้งานใหม่ และปิดใช้งานต้องเกิดใน transaction เดียวกัน
- ระบบควรแสดงคำเตือนชัดเจนว่าไฟล์ต้องเป็น Full Snapshot ก่อนผู้ใช้ยืนยัน
- ต้องตรวจโครงสร้างไฟล์และข้อผิดพลาดทั้งหมดก่อนคำนวณรายการที่จะถูกปิดใช้งาน
