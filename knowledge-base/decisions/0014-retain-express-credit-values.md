# Decision 0014: เก็บวันเครดิตและยอดวงเงินตาม Express

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## การตัดสินใจ

- เก็บ `เครดิต (วัน)` เป็นเลขจำนวนเต็มใน `credit_days`
- เก็บ `ยอดวงเงิน` เป็นเลขทศนิยมใน `credit_limit`
- เก็บค่า `0` และ `0.00` ตามข้อมูล Express
- ยังไม่ตีความว่าค่าศูนย์หมายถึงไม่มีเครดิต ไม่มีวงเงิน หรือไม่จำกัดวงเงิน

## Validation

- ค่าว่างยอมรับได้
- เมื่อมีค่า เครดิตต้องเป็นเลขจำนวนเต็มตั้งแต่ 0 ขึ้นไป
- เมื่อมีค่า ยอดวงเงินต้องเป็นตัวเลขตั้งแต่ 0 ขึ้นไป
- หากค่าไม่ใช่ตัวเลขตามรูปแบบ ต้องแสดงข้อผิดพลาดและบล็อก Import ทั้งไฟล์
