# Decision 0018: ค่าเริ่มต้นแสดง Supplier ที่ใช้งาน

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## การตัดสินใจ

- เมื่อเปิดหน้า Supplier ให้กรองสถานะ `ใช้งาน` เป็นค่าเริ่มต้น
- ผู้ใช้เปลี่ยนตัวกรองเป็น `ไม่ใช้งาน` หรือ `ทั้งหมด` ได้
- Supplier ที่ไม่ใช้งานยังค้นหา เปิดดูรายละเอียด และดูประวัติเดิมได้

## เหตุผล

รายการที่ไม่ใช้งานไม่ควรรบกวนการทำงานประจำ แต่ต้องรักษาการเข้าถึงข้อมูลและเอกสารย้อนหลัง
