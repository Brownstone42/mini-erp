# Decision 0025: Express เป็นแหล่งข้อมูลหลักของ Customer ที่ Import

วันที่: 2026-08-10  
สถานะ: ยืนยันแล้ว

## การตัดสินใจ

สำหรับทุก field ของ Customer ที่นำเข้าจาก Express ระบบต้องใช้ค่าจากไฟล์ล่าสุดเป็นหลัก:

- ค่าใหม่เขียนทับค่าเดิม
- หากไฟล์รอบใหม่เป็นค่าว่าง ต้องล้างค่าเดิมใน ERP ให้เป็นค่าว่าง
- ห้ามคงค่าจาก Import รอบก่อนเมื่อ Express ส่งค่าว่างมาแล้ว

กฎนี้ใช้เฉพาะ field ที่ประกาศว่า Express เป็นเจ้าของข้อมูลใน Customer Data Dictionary
