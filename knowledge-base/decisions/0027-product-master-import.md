# Product master import

- ใช้รหัสสินค้าเดิมจาก Express เป็นรหัสหลัก
- ไฟล์แต่ละรอบเป็น Full Snapshot และ Express เป็นแหล่งข้อมูลหลัก
- รหัสเดิมให้อัปเดตข้อมูล รวมถึงเขียนค่าว่างทับค่าเดิม
- สินค้าที่หายจากไฟล์เปลี่ยนเป็นไม่ใช้งาน และเปิดใช้อัตโนมัติเมื่อกลับมา
- Import ต้อง Preview ก่อนและบันทึกทั้งหมดแบบ transaction เดียว
- Product และ Product Category อ่านอย่างเดียว การแก้ไขต้องมาจาก Express
- เก็บข้อมูลหน่วยซื้อ หน่วยขาย ตัวคูณ ราคามาตรฐาน และสินค้าทดแทนตามไฟล์
- สินค้าทดแทนเก็บเป็นข้อความ ไม่สร้างความสัมพันธ์
- Supplier ของสินค้าต้องอ้างอิง Supplier Master Data ที่มีอยู่ หากไม่พบให้หยุด Import ทั้งไฟล์
- แยก Product Category เป็น Master Data และ Product อ้างอิงหมวดด้วยรหัสเดิมจาก Express
