# Decision 0003: Express เป็นแหล่งข้อมูลหลักของ Supplier ที่ Import

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## บริบท

ข้อมูล Supplier รอบใหม่อาจแตกต่างจากข้อมูลที่มีอยู่ใน ERP รวมถึงบาง field ที่เปลี่ยนเป็นค่าว่าง

## การตัดสินใจ

สำหรับ field ที่นำเข้าจาก Express ระบบต้องใช้ไฟล์ Express ล่าสุดเป็นแหล่งข้อมูลหลัก:

- ค่าใหม่เขียนทับค่าเดิม
- ค่าว่างเขียนทับและล้างค่าเดิม
- ผลลัพธ์หลัง Import ต้องสะท้อนข้อมูลในไฟล์ล่าสุด

## ขอบเขต

กฎนี้ใช้เฉพาะ field ที่ประกาศว่า Express เป็นเจ้าของใน Supplier Data Dictionary เท่านั้น

Field ที่เพิ่มขึ้นภายใน ERP และไม่มีอยู่ในไฟล์ Express ต้องไม่ถูกล้างจากการ Import

## ผลกระทบ

- หน้า Preview ควรแสดงค่าที่กำลังจะเปลี่ยน รวมถึงค่าที่กำลังจะถูกล้าง
- ระบบต้องแยก field ที่มาจาก Express ออกจาก field ที่ผู้ใช้กรอกเพิ่มภายใน ERP
- ควรเก็บประวัติ Import เพื่อค้นหาว่าข้อมูลถูกเปลี่ยนจากไฟล์ใดและเมื่อใด
