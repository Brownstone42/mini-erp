# Decision 0015: เก็บประเภท Supplier จาก Express

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## การตัดสินใจ

- เก็บประเภท Supplier จากหัวข้อกลุ่มในรายงาน Express เป็น `supplier_type`
- ค่าในหัวข้อกลุ่มต้องถูกนำไปใช้กับ Supplier ทุกรายการภายใต้กลุ่มนั้น
- ไม่ hard-code ค่า `ผู้จำหน่ายประจำ` ในระบบ Import

## ข้อมูลตัวอย่าง

ไฟล์ `express_suppliers_2026-08-04.csv` มีประเภท `ผู้จำหน่ายประจำ` เพียงประเภทเดียว และครอบคลุม Supplier ทั้ง 957 รายการ โดยรวมรหัสเดิมแบบมีขีด 3 รหัสด้วย

## เหตุผล

แม้ไฟล์ตัวอย่างจะมีประเภทเดียว แต่การอ่านค่าจากหัวข้อรายงานช่วยรักษาข้อมูลตาม Express และรองรับประเภทอื่นหากปรากฏในไฟล์อนาคต
