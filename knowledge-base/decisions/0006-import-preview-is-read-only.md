# Decision 0006: Preview เป็นแบบอ่านอย่างเดียว

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## การตัดสินใจ

ผู้ใช้ไม่สามารถแก้ชื่อ ที่อยู่ เบอร์โทร หรือข้อมูล Supplier อื่นบนหน้า Preview ได้

หากพบข้อมูลผิด ผู้ใช้ต้องกลับไปแก้ข้อมูลใน Express แล้ว Export และ Upload ไฟล์ใหม่

## เหตุผล

Express เป็นแหล่งข้อมูลหลักของ field ที่นำเข้า การห้ามแก้ระหว่าง Import ช่วยป้องกันไม่ให้ข้อมูล Express และ ERP แตกต่างกัน

## ผลกระทบ

- Preview ต้องแสดงข้อผิดพลาดให้ค้นหารายการต้นทางได้ง่าย โดยระบุรหัส Supplier และ field ที่มีปัญหา
- หน้า Preview ไม่ต้องมี form control สำหรับแก้ไขข้อมูล
- ผู้ใช้ต้องสามารถยกเลิกรอบปัจจุบันและเลือกไฟล์ใหม่ได้
