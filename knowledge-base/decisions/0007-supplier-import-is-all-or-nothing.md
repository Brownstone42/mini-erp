# Decision 0007: Supplier Import ต้องสำเร็จทั้งชุด

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## การตัดสินใจ

หากไฟล์ Supplier มีข้อผิดพลาดแม้แต่หนึ่งรายการ ระบบต้องบล็อกการ Import ทั้งไฟล์

ระบบห้ามนำเข้าเฉพาะรายการที่ผ่านแล้วข้ามรายการที่ผิด

## พฤติกรรมที่ต้องการ

- หน้า Preview แสดงข้อผิดพลาดทั้งหมดที่ตรวจพบ
- ปุ่มยืนยัน Import ใช้งานไม่ได้ขณะที่ยังมีข้อผิดพลาด
- ผู้ใช้ต้องแก้ข้อมูลใน Express แล้ว Upload ไฟล์ใหม่
- หากเกิดข้อผิดพลาดระหว่างการบันทึก ระบบต้องย้อนคืนการเปลี่ยนแปลงทั้งหมดของรอบนั้น

## ผลกระทบทางเทคนิค

การสร้างและอัปเดต Supplier ในหนึ่งรอบ Import ต้องอยู่ภายใต้ transaction เดียวกัน เพื่อให้ผลลัพธ์เป็นแบบสำเร็จทั้งหมดหรือไม่เปลี่ยนข้อมูลเลย
