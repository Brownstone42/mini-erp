# Decision 0010: Field บังคับของ Supplier

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## การตัดสินใจ

Supplier ต้องมีข้อมูลบังคับเพียงสอง field:

- รหัส Supplier
- ชื่อ Supplier

ข้อมูลต่อไปนี้สามารถว่างได้:

- ที่อยู่
- เบอร์โทรศัพท์
- ชื่อผู้ติดต่อ
- เลขประจำตัวผู้เสียภาษี
- Email
- สาขา
- เครดิตและวงเงิน
- รหัสบัญชี

## ผลกระทบ

- หากรหัสหรือชื่อว่างแม้แต่หนึ่งรายการ ต้องบล็อกการ Import ทั้งไฟล์
- Field ที่ไม่บังคับต้องไม่ทำให้ Import ล้มเหลวเพียงเพราะไม่มีค่า
- เมื่อ field ที่ไม่บังคับมีค่า ระบบอาจตรวจรูปแบบตามกฎที่จะกำหนดเพิ่มเติม
