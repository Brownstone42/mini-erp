# Sales History import

- ใช้ข้อมูลล่าสุดตามช่วงที่ผู้ใช้งาน Export ไม่บังคับย้อนหลังหลายปี
- แต่ละไฟล์เป็น Snapshot ครบถ้วนภายในช่วงวันที่ในหัวรายงาน
- Import ซ้ำช่วงเดิมต้องอัปเดตรายการ และรายการที่หายไปเปลี่ยนเป็นไม่ใช้งานโดยไม่ลบประวัติ
- เก็บเอกสารลงวันที่ล่วงหน้าตาม Express และการวิเคราะห์นับเมื่อถึงวันที่เอกสาร
- เก็บจำนวนและยอดคืนเป็นค่าบวกตามต้นฉบับ แต่ค่าที่ใช้วิเคราะห์เป็นค่าลบ
- เก็บทุกคอลัมน์จาก Express แม้ Forecast รุ่นแรกยังไม่ได้ใช้
- เก็บหน่วยในรายงานเป็นข้อความต้นฉบับ และใช้หน่วยขาย/ตัวคูณจาก Product Master เพื่อแปลงจำนวนฐาน
- รหัสรายการภายในมาจากเลขที่เอกสาร รหัสสินค้า เอกสารอ้างอิง และลำดับซ้ำภายในเอกสาร
- Preview ก่อน Import และบันทึกทั้งหมดแบบ transaction เดียว
- หน้าจออ่านอย่างเดียว เริ่มจากหนึ่งแถวต่อหนึ่งรายการสินค้า และเปิดดูรายการทั้งเอกสารได้
