# Decision 0012: ตัด whitespace หัวและท้ายของข้อความ

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## การตัดสินใจ

ก่อนแสดง Preview และ Import ระบบต้องตัด whitespace ที่หัวและท้ายของทุก field แบบข้อความ

กฎนี้รวมช่องว่างปกติและ whitespace พิเศษที่อาจติดมาจากไฟล์ Express

## สิ่งที่ไม่ทำ

- ไม่ยุบช่องว่างหลายตัวที่อยู่ภายในข้อความ
- ไม่เปลี่ยนตัวพิมพ์เล็กหรือตัวพิมพ์ใหญ่
- ไม่แก้การสะกด
- ไม่จัดรูปแบบเบอร์โทร ที่อยู่ หรือเลขผู้เสียภาษี

## Validation

Field บังคับ เช่นรหัสและชื่อ Supplier ต้องตรวจว่าไม่ว่างหลังจากตัด whitespace แล้ว
