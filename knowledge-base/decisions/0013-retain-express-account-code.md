# Decision 0013: เก็บเลขที่บัญชีจาก Express ไว้ก่อน

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## การตัดสินใจ

- นำค่า `เลขที่บัญชี` จากไฟล์ Express มาเก็บใน Supplier
- เก็บเป็น Text ตามค่าจาก Express
- ใช้ชื่อเชิงระบบชั่วคราวว่า `express_account_code` เพื่อไม่ทำให้เข้าใจว่าเชื่อมกับระบบบัญชีใหม่แล้ว
- ยังไม่ใช้ค่านี้ควบคุมการลงบัญชีหรือพฤติกรรมอื่นใน Phase แรก
- ยังไม่ตรวจสอบค่านี้กับ Chart of Accounts

## เหตุผล

ยังไม่ทราบบทบาทของเลขที่บัญชีใน ERP ใหม่ แต่ข้อมูลอาจจำเป็นต่อการอ้างอิงหรือ migration ในอนาคต จึงเก็บข้อมูลต้นทางไว้ก่อนโดยไม่ผูกความหมายเกินกว่าที่ทราบ

## ทบทวนภายหลัง

เมื่อออกแบบระบบบัญชีและ Chart of Accounts ต้องพิจารณาว่า field นี้ควรถูก map, ย้าย หรือเก็บเป็นข้อมูลอ้างอิงเดิมต่อไป
