# Decision 0020: ข้อมูล Supplier จาก Express เป็น Read-only

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## การตัดสินใจ

- ข้อมูล Supplier ทุก field ที่มาจาก Express แสดงได้แต่แก้ไขใน ERP ไม่ได้
- กฎนี้ใช้ทั้งหน้ารายการ หน้ารายละเอียด และหน้า Preview
- หากข้อมูลผิด ผู้ใช้ต้องแก้ที่ Express แล้ว Import Full Snapshot รอบใหม่

## เหตุผล

Express เป็นแหล่งข้อมูลหลัก การแก้ค่าเดียวกันใน ERP จะทำให้ข้อมูลสองระบบไม่ตรงกันและถูกเขียนทับในการ Import ครั้งถัดไป

## ขอบเขตในอนาคต

หาก ERP มี field เพิ่มเติมที่ไม่มีใน Express สามารถกำหนดให้แก้ไขได้แยกต่างหาก โดยต้องระบุเจ้าของข้อมูลของแต่ละ field ให้ชัดเจน
