# Decision 0004: ไม่เก็บไฟล์ CSV ต้นฉบับหลัง Import

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## การตัดสินใจ

ระบบใช้ไฟล์ CSV เพื่อ Preview, ตรวจสอบ และ Import เท่านั้น เมื่อกระบวนการสิ้นสุดแล้วต้องไม่เก็บไฟล์ต้นฉบับไว้ในระบบ

## ผลกระทบ

- ต้องลบไฟล์ชั่วคราวทั้งกรณี Import สำเร็จ ล้มเหลว หรือผู้ใช้ยกเลิก
- ต้องไม่บันทึกเนื้อหา CSV ลงใน log
- ประวัติการ Import สามารถเก็บเฉพาะ metadata และผลสรุป เช่น ชื่อไฟล์ เวลา ผู้ดำเนินการ จำนวนรายการที่สร้าง อัปเดต และไม่สำเร็จ
- ผู้ใช้จะไม่สามารถดาวน์โหลดไฟล์ต้นฉบับย้อนหลังจาก ERP ได้
