# Decision 0001: ใช้รหัส Supplier เดิมจาก Express

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## บริบท

ข้อมูล Supplier ที่ Export จาก Express มีรหัสเดิม เช่น `AP00001` และรหัสดังกล่าวถูกใช้ระบุตัว Supplier ในงานปัจจุบัน

## การตัดสินใจ

ERP ใหม่จะใช้รหัส Supplier เดิมจาก Express เป็นรหัส Supplier หลัก โดยไม่สร้างรหัสใหม่มาทดแทนระหว่างการนำเข้าข้อมูล

## ผลกระทบ

- `supplier_code` ต้องเป็น Text, ห้ามว่าง และต้องไม่ซ้ำ
- การ Import ซ้ำต้องค้นหารายการเดิมด้วย `supplier_code` และอัปเดตข้อมูลเดิมจากไฟล์ใหม่
- ต้องรักษาตัวอักษร ตัวเลข และเลขศูนย์นำหน้าตามต้นฉบับ
- หากไม่พบรหัสในระบบ ให้สร้าง Supplier ใหม่
- ต้องรายงานผลแยกรายการที่สร้างใหม่ อัปเดต และไม่สำเร็จ
- กติกาสำหรับค่าว่างในไฟล์ใหม่ยังต้องตัดสินใจเพิ่มเติม
