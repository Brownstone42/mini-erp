# Decision 0002: Supplier Import แบบสร้างใหม่หรืออัปเดต

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## บริบท

ผู้ใช้อาจ Upload ข้อมูล Supplier จาก Express มากกว่าหนึ่งครั้ง และไฟล์รอบใหม่อาจมีทั้ง Supplier เดิมและ Supplier ที่เพิ่งเพิ่ม

## การตัดสินใจ

ระบบจะจับคู่ Supplier ด้วย `supplier_code`:

- หากพบรหัสเดิม ให้อัปเดตรายการเดิมจากไฟล์ใหม่
- หากไม่พบรหัส ให้สร้าง Supplier ใหม่
- ห้ามสร้าง Supplier ซ้ำเมื่อรหัสตรงกัน
- ข้อมูลทุก field ที่อยู่ในขอบเขตการ Importต้องตรงตามไฟล์ Express ล่าสุด
- หาก field ในไฟล์ Express เป็นค่าว่าง ต้องล้างค่าเดิมใน ERP ให้เป็นค่าว่างด้วย

## ผลกระทบ

- การ Preview ต้องระบุได้ว่าแต่ละรายการจะถูกสร้างใหม่หรืออัปเดต
- รายงานผลต้องแยกจำนวนที่สร้างใหม่ อัปเดต และไม่สำเร็จ
- ระบบควรเก็บวันเวลาและผู้ดำเนินการ Import เพื่อการตรวจสอบย้อนหลัง
- Field ที่ผู้ใช้เพิ่มใน ERP และไม่ได้อยู่ในขอบเขตการ Import ต้องไม่ถูกล้างโดยไฟล์ Express
