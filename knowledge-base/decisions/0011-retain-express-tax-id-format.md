# Decision 0011: เก็บเลขผู้เสียภาษีตามรูปแบบจาก Express

วันที่: 2026-08-04  
สถานะ: ยืนยันแล้ว

## การตัดสินใจ

- เก็บเลขประจำตัวผู้เสียภาษีเป็น Text ตามค่าที่ Express ส่งมา
- ไม่บังคับว่าต้องเป็นเลข 13 หลัก
- ไม่เติม ตัด หรือคำนวณเลขใหม่
- รูปแบบเลขผู้เสียภาษีไม่ใช่ข้อผิดพลาดที่บล็อก Import

## เหตุผล

ข้อมูล Supplier เดิมมีทั้งเลขรูปแบบ 13 หลักและเลขรูปแบบเก่า 10 หลัก และ Express เป็นแหล่งข้อมูลหลักสำหรับการ Import

## ผลกระทบ

- ต้องรักษาเลขศูนย์นำหน้า
- หน้า Preview สามารถแสดงรูปแบบที่ต่างกันเป็นข้อมูลประกอบได้ แต่ไม่แสดงเป็น blocking error
- การตรวจสอบความถูกต้องทางภาษี หากต้องการในอนาคต ต้องเป็นกระบวนการแยกจาก Master Data Import รอบนี้
