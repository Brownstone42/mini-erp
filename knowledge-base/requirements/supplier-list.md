# Supplier List Requirements

สถานะ: Discovery

## เป้าหมาย

เป็นหน้าหลักสำหรับค้นหา ตรวจสอบ และเปิดดูข้อมูล Supplier

## Requirement ที่ยืนยันแล้ว

- เข้าถึงจาก `Master Data > Supplier`
- แสดง Supplier เป็นตาราง
- มีปุ่ม `Import from Express` ด้านบนของหน้า
- รองรับ Supplier สถานะใช้งานและไม่ใช้งาน
- การ Import เปิด workflow Upload และ Preview ของ Supplier โดยเฉพาะ
- เมื่อเปิดหน้าครั้งแรก ให้แสดงเฉพาะ Supplier สถานะใช้งาน
- มีตัวกรองสถานะ `ใช้งาน`, `ไม่ใช้งาน` และ `ทั้งหมด`
- Supplier ที่ไม่ใช้งานยังเปิดดูรายละเอียดและประวัติเดิมได้
- มีช่องค้นหาหลักหนึ่งช่อง
- ช่องค้นหาต้องค้นพร้อมกันจากรหัส Supplier, ชื่อ Supplier, เลขประจำตัวผู้เสียภาษี และเบอร์โทรศัพท์
- การค้นหาต้องทำงานร่วมกับตัวกรองสถานะที่เลือกอยู่
- เมื่อเปิดรายละเอียด Supplier ข้อมูลทุก field ที่มาจาก Express ต้องเป็นแบบอ่านอย่างเดียว
- ผู้ใช้แก้ไขข้อมูลจาก Express โดยตรงใน ERP ไม่ได้
- หากข้อมูลไม่ถูกต้อง ต้องแก้ที่ Express แล้ว Import Full Snapshot รอบใหม่

## Column ในตาราง

แสดงตามลำดับเบื้องต้น:

1. รหัส Supplier
2. ชื่อ Supplier
3. ประเภท Supplier
4. เลขประจำตัวผู้เสียภาษี
5. เบอร์โทรศัพท์
6. เครดิต (วัน)
7. สถานะ
8. อัปเดตล่าสุด

ข้อมูลอย่างที่อยู่ ชื่อผู้ติดต่อ วงเงิน และเลขที่บัญชีไม่ต้องแสดงในตารางหลัก แต่แสดงในหน้ารายละเอียด Supplier

## ประเด็นที่ต้องตัดสินใจ

- รูปแบบหน้ารายละเอียด Supplier
