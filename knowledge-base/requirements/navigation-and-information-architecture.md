# Navigation and Information Architecture

สถานะ: Discovery

## เมนูหลัก

### Master Data

พื้นที่รวมข้อมูลหลักที่ถูกใช้อ้างอิงโดยส่วนต่าง ๆ ของ ERP และจะมีรายการเพิ่มขึ้นในอนาคต

เมนูย่อยที่ยืนยันแล้ว:

- Supplier
- Customer

## หลักการ

- Supplier และ Customer ต้องมีหน้าและ workflow แยกจากกัน
- ไม่สร้างหน้า Upload Supplier/Customer แบบรวมประเภทข้อมูลไว้ในหน้าจอเดียว
- โครงสร้างเมนู Master Data ต้องเพิ่มข้อมูลประเภทอื่นได้โดยไม่ต้องเปลี่ยน navigation หลัก

## โครงสร้างเบื้องต้น

```text
Master Data
├── Supplier
└── Customer
```

## Supplier

- เมื่อเข้าเมนู Supplier ต้องแสดงตารางรายชื่อ Supplier ทั้งหมด
- มีปุ่ม `Import from Express` อยู่ในส่วนคำสั่งด้านบนของหน้า
- การ Import เป็น action ภายในหน้า Supplier ไม่ใช่เมนูย่อยอีกระดับ
- หน้า Supplier ต้องรองรับการค้นหา เปิดดูรายละเอียด และแสดงสถานะใช้งาน/ไม่ใช้งาน

## ประเด็นที่ต้องตัดสินใจ

- รูปแบบการค้นหา กรอง และดูรายละเอียด
- สิทธิ์สำหรับดู เพิ่ม แก้ไข Import และปิดใช้งาน
