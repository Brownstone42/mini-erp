# กรรมการลงนาม

## Goal

จัดเก็บข้อมูลผู้มีอำนาจลงนามและรูปประกอบสำหรับนำไปใช้กับใบเสนอราคาและเอกสารอื่นในอนาคต

## Requirements

- รองรับกรรมการลงนามหลายคน
- เก็บชื่อ-นามสกุล เบอร์โทรศัพท์ และ Email ใน PostgreSQL
- อัปโหลดรูปลายเซ็นและตราประทับบริษัทเป็น PNG, JPG หรือ WebP ขนาดไม่เกิน 5 MB ต่อไฟล์
- เก็บไฟล์รูปใน Firebase Storage และเก็บเฉพาะ Storage path ใน PostgreSQL
- ผู้ใช้ที่ผ่านการ Login อ่านรายการและรูปได้
- เฉพาะบัญชีผู้ดูแลระบบที่กำหนดใน Storage Rules อัปโหลดหรือเขียนทับไฟล์ได้
- ปิดและเปิดใช้งานรายการได้โดยไม่ลบข้อมูลหรือไฟล์เดิม
- ยังไม่นำข้อมูลนี้ไปใส่ในใบเสนอราคาจนกว่าจะกำหนดกฎการเลือกผู้ลงนาม

## Acceptance criteria

- บันทึกชื่ออย่างเดียวได้ ส่วนเบอร์ Email และรูปเป็นข้อมูลทางเลือก
- Preview รูปก่อนบันทึกได้
- ไฟล์ผิดประเภทหรือเกิน 5 MB ถูกปฏิเสธก่อน Upload
- ถ้าบันทึกฐานข้อมูลไม่สำเร็จ ระบบลบไฟล์ที่ Upload ในครั้งนั้นออก
- รายการแสดงรูปตัวอย่างและสถานะใช้งาน
