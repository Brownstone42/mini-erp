# Knowledge Base

คลังความรู้ของโครงการ แยกจาก source code ของเว็บแอป

## โครงสร้าง

- `requirements/` สิ่งที่ระบบต้องทำและ acceptance criteria
- `processes/` คู่มือปฏิบัติงาน เช่น การ Export ข้อมูลจาก Express
- `data-dictionary/` ความหมาย ชนิด และกฎของแต่ละ field
- `decisions/` บันทึกสิ่งที่เลือก เหตุผล และทางเลือกที่ไม่เลือก
- `samples/` ตัวอย่างข้อมูลที่ปกปิดข้อมูลจริงแล้ว
- `meeting-notes/` บันทึกการคุยและประเด็นที่ยังไม่สรุป
